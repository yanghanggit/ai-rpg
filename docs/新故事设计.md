# 《大渊》设计文档（草稿）

## 项目概述

- **目标**：将《道诡异仙》的中式克苏鲁修仙世界观与《血源诅咒》的“认知崩溃式”动作RPG玩法融合，打造一款以“真实与虚幻”为核心冲突的民国风恐怖狩猎游戏。
- **灵感来源**：
  - 《血源诅咒》：维多利亚哥特+克苏鲁古神，强调通过“灵视”发现隐藏真相，战斗以攻为守。
  - 《道诡异仙》：中式民俗志怪+诡异修仙，主角“心素”体质能“修假为真”，在现实与修仙世界间撕裂认知。

## 核心命名

### 《大渊》

- “渊”指深渊、深不可测的未知，暗合“认知的深渊”与“世界深处的真相”。
- 独立命名，不暴露任何原著信息，也不提前揭示“双世界/精神病/修仙”等核心设定。

## 1. 世界设定：表世界与里世界

### 表世界 —— **民国精神病院（虚假的“安全屋”）**

- **表象**：民国年间的“济世疗养院”（或类似名称），一座由教会或地方乡绅资助的旧式医院。斑驳的砖墙、木质地板、昏暗的煤油灯、生锈的铁窗，空气中弥漫着草药与消毒水混合的气味。
- **本质**：主角为逃避“大傩”残酷现实而构建的认知牢笼，是“天道”为“心素”设立的缓冲区。
- **时代优势**：民国本身就是“中西碰撞、新旧交替”的认知撕裂期，与核心矛盾高度共振。
- **系统功能**：
  - 提供叙事碎片（毛笔手写的病案、泛黄的药方、留声机录音、黑白照片）。
  - 唯一的安全存档点，但停留过久会听到远处传来的**买报童吆喝**或**教堂钟声**——大傩世界的边界正在渗透。
  - 每次死亡或使用特定道具，会被强制拉回此处。

### 里世界 —— **大傩（真实的猎场）**

- **表象**：扭曲的中国古代山川村镇，道观坍塌、神像流泪、河流逆流、天空呈暗红或紫色，唢呐与锣鼓声在远处回荡。
- **本质**：由癫狂的“司命”（上位者）意志直接塑造的真实世界，物理法则取决于“认知值”。
- **系统功能**：
  - 全部战斗、探索、Boss战、法术学习在此发生。
  - “认知值”（替代“灵视”）决定你能看到多少隐藏路径和弱点，同时也加速理智崩溃。

### 两者的关系

> 表世界是里世界的“镜像谎言”，里世界是表世界的“残酷真相”。主角在两个世界间穿梭，本质上是在**撕碎自己用于自我保护的安全谎言**。
> **时间线设定**：表世界为“民国年间”（具体年份模糊处理），里世界为“混沌的古代”。两者在美术风格上统一于“中式传统建筑美学”，避免现代与古代的视觉割裂。

## 2. 核心矛盾：寻求自我与理解世界

主角的核心问题不再是“如何逃离”，而是 **“我究竟是谁？世界究竟是什么？”**

| 维度 | 表世界（民国精神病院） | 里世界（大傩） |
| ------ | ----------------------- | --------------- ｜
| 对“我”的认知 | 一个被诊断为疯癫的病人 | 一个“心素”，能以认知扭曲现实 |
| 对“世界”的认知 | 唯物主义现实，诡异皆为幻觉 | 天道已死，仙佛皆魔，底层逻辑是混乱 |
| 矛盾本质 | “我是病人还是神？” | “世界是正常还是疯狂？” |

**驱动逻辑**：通过猎杀和探索收集“真相碎片”，逐步拼凑出自我与世界的真实面貌，最终决定成为“病人”、“神”还是“骗子”。

## 3. 阵营设计（基于不同的认知解释）

每个阵营不是可加入的势力，而是对“天道真相”持不同解释的学派，引导玩家走向不同的认知路径。

| 阵营 | 对“自我”的解读 | 对“世界”的解读 | 游戏中的作用 |
| ------ | ---------------- | ---------------- | ------------- |
| **坐忘道（骗子）** | “你只是我们的一场骗局。” | “世界就是一场大骗局，一切不可信。” | 提供半真半假的线索，可能指引捷径，也可能引入陷阱；是“解谜的干扰项”。 |
| **三清残党（修仙正统）** | “你是被天道选中的修行者。” | “天道已死，但可以重启。” | 给出框架性指引，劝说玩家按“正统路线”去修复天道。 |
| **疯病友（济世疗养院的住民）** | “你就是个可怜的病人。” | “世界正常，不正常的是你。” | 提供反向锚点，用质疑强化玩家的自我怀疑，但偶尔藏着大傩世界的真相碎片。 |

## 4. 游戏流程驱动：认知战争

1. 进入大傩 → 接触新阵营 → 获得一个关于“你是谁”和“世界是什么”的叙事。
2. 按该叙事探索、猎杀、收集碎片 → 获得的线索会部分印证或完全推翻先前叙事。
3. 陷入更深的困惑 → 回到表世界（病房），从医嘱和病友呓语中寻找参照。
4. 带着新困惑再次进入大傩，循环往复，直至拼凑出足以做出最终决定的“完整真相”。

## 5. 核心体验压缩总结

| 维度 | 定义 |
| ------ | ------ |
| **游戏名称** | **《大渊》** |
| **表世界（谎言）** | 民国精神病院（认知的囚笼）：提供碎片与安全暂停。 |
| **里世界（真相）** | 大傩（认知的猎场）：提供战斗、探索与真实的叙事核心。 |
| **核心矛盾** | “我是谁？”（自我认知）与“天道是什么？”（世界认知）之间的永恒撕裂。 |
| **游戏目标** | 收集“真相碎片”，最终在三个结局（病人/神/骗子）中做出选择。 |

## 6. 关于民国时期的时间段选择

我建议将背景设定在 “黄金十年”的后期，即1930年代初期（约1930-1934年）。这个选择能在混乱与秩序、传统与变革之间找到最佳平衡点，为《大渊》的世界观提供最理想的舞台。

以下是具体的分析：

⏳ 民国时期的几个关键阶段
民国通常指1912年至1949年，大致可分为以下几个阶段：

北洋军阀时期 (1912-1928年)：辛亥革命后，中央政权衰微，地方军阀割据混战，社会极度动荡。

“黄金十年” (1927-1937年)：国民政府定都南京后，在名义上统一了中国，并在经济、文化、基建上取得发展，被誉为“短暂盛世”。

抗日战争时期 (1937-1945年)：全面抗战爆发，民族矛盾上升为最主要的社会矛盾。

解放战争时期 (1945-1949年)：国共内战，社会面临崩溃。

🎭 各阶段作为游戏背景的优劣分析
北洋军阀时期 (1912-1928)
优势：极致的混乱与无序，非常适合描绘一个礼崩乐坏、妖孽横行的世界。政权的频繁更迭也与“真相难觅”的主题相契合。

劣势：纯粹的混乱可能使“表世界”缺乏稳定的锚点，让玩家对“秩序”的感知变得模糊，削弱了“在虚假中寻求安定”的对比感。

抗日战争时期 (1937-1945)
优势：民族危亡的背景能极大地增强故事的悲剧性和宿命感。

劣势：外敌入侵的历史背景过于沉重和具体，可能会将游戏的核心矛盾（内在的认知撕裂）引向外部的民族矛盾，冲淡了《大渊》原本的哲学与心理恐怖内核。

解放战争时期 (1945-1949)
优势：社会崩溃前夕的绝望感极强，适合描绘末日光景。

劣势：与抗战时期类似，过于明确的政治与历史背景可能会喧宾夺主。

✨ 为什么是“黄金十年”后期 (1930-1934)？
“黄金十年”本身就是一个充满矛盾的时代。选择其后期，可以同时获得以下优势：

新旧碰撞的完美舞台：西方现代文明与古老的传统激烈碰撞。这意味着“济世疗养院”里，可以同时出现西医的手术台和中医的符水，这种视觉与认知的撕裂感，完美呼应了主角在两个世界间的挣扎。

表面平静下的暗流涌动：这个时期，大城市看似繁华，但农村正在经历崩溃，社会矛盾暗流涌动。这种“金玉其外，败絮其中”的氛围，与《大渊》“表世界是谎言，里世界是真相”的设定高度吻合。

丰富的文化符号宝库：这是一个文化上极具辨识度的时代。你可以自然地融入留声机、旗袍、黄包车、大洋楼等元素，让表世界的民国风情更具沉浸感。

恰到好处的时间距离：1930年代距离“五四”新文化运动不远，科学的理性与对“赛先生”的崇拜，恰好可以用来反衬“里世界”的不可知与疯狂，让“我究竟是疯了还是看到了真实”这个问题变得更加尖锐。

💎 总结
将时间锚定在1930年代初期（约1930-1934年），可以最大化地利用“黄金十年”的矛盾性与丰富性，为《大渊》提供一个既独特又充满叙事潜力的时代画布。

这个时期的“表世界”将是一个表面上正在“进步”与“繁荣”，但内里早已被危机与恐惧蛀空的时代，就像一座灯火通明却鬼影幢幢的精神病院，完美地包裹着“大傩”那个疯狂而真实的里世界。
