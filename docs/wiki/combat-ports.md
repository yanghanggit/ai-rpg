# 三端化思维（攻击端 / 防御端 / 运转端）

---

## 定位

端口化思维是跳出固定流派、从**攻击端 / 防御端 / 运转端**三个维度评估与构筑卡组的方法论，核心原则是「缺啥补啥」。它既用于给卡牌原型分类，也用于指导卡牌设计。

## 攻击端（目标：造成伤害）

- 前端伤害：无需准备、打出即生效，用于解决小怪和快速削血。
- 成长性伤害：伤害随战斗进程逐步提升，用于击败高血量 Boss。
- 铺垫性攻击支持：为最终伤害做铺垫的 Buff / Debuff（如力量、易伤）。

## 防御端（目标：避免生命值归零）

- 前端防御：打出后立即提供格挡的即时手段。
- 成长性防御：格挡量随战斗进程逐步提升（跨回合、持续格挡）。
- 特殊防御机制：不直接给格挡数字，但能减少或规避伤害（虚弱、反伤、状态保护、回血）。

## 运转端（目标：最大化每回合可用资源）

- 过牌：每回合抽取更多牌，更快找到核心牌并滤过无用牌。
- 加费：获得额外能量，有足够费用打出所有好牌。
- 启动速度：让卡组在前 1~2 回合稳定运转，度过启动期的脆弱阶段。

## 与当前系统的映射

攻击端、防御端已被 `Card` 字段覆盖（伤害、格挡、词缀、目标类型）。运转端尚无对应字段——抽牌与能量目前由系统层（抽牌堆、回合能量）决定，`Card` 没有「过牌」「加费」字段，因此暂不进入卡牌原型分类，留待后续。

## 三端关系

- 攻击端决定能多快解决战斗；防御端决定能撑多久；运转端决定攻防协同的稳定性。
- 强卡组 = 三端平衡 + 合理的前端/成长性配置 + 足够快的启动速度。
