# 世界快照持久化（World Persistence）

世界快照持久化是开发期的状态留痕层：把一次运行点的 `WorldState` 与 `PlayerSession` 连同各领域子状态，序列化为一棵明文目录树落盘，供开发者与 Agent 直接审阅、比对差异、判断运行状态。它是「人可读优先」的临时方案，不是最终存储——正式存储应落到数据库。

## 设计意图

- **明文、可审阅**：各领域状态拆分为独立文件，目录结构即状态结构，可逐文件打开查看，也便于比对两个运行点的差异。
- **快照而非日志**：每份落盘都是一份完整、自足的状态切片，读取任意一份即可复位世界并继续推进，命令间不依赖进程内记忆。
- **开发期专用**：不追求写入吞吐、增量更新或查询能力，这些交由未来的数据库承担。

## 与其他系统的关系

- 由各游戏管道驱动：家园、战斗、副本、开场等动作完成一个回合后，产出一份新快照。
- 被 AI 操作 CLI 消费：读取某份快照还原世界后继续执行下一动作，形成「读快照 → 动作 → 写新快照」的无状态循环。
  → 参见：[AI 操作 CLI（run_agent_game.py）](run-agent-game.md)
- 快照承载的世界与玩家会话模型属于核心模型层，其语义不在本系统定义。
