# 奇幻故事设计草稿（作品名待定）

> ⚠️ 本文档用于作者梳理世界设定与思路，属设计草稿。demo 已按本文方向落地，但具体命名与数值可能随时调整，**以 `demo/world.py` 为准**。

## 项目定位

**奇幻世界 × 多文化英雄 × 穿越者主角 × DBG（卡组构建）**。

- **基底是奇幻**，不是传统 DND 那种明亮高魔、地牢爬行的范式；现阶段也不急着铺陈深刻厚重的大背景。
- **叙事节奏**：站在玩家视角，一上来就灌入宏大的世界格局并不合适——**先把「佣兵接单 → 执行任务 → 返回据点」这个循环跑顺**，深度留待后续按需补充。
- **多文化拼贴**：东方侠客与西方骑士同处一世，诸国英雄传统并存，职业与文化感强；只取"奇幻框架 + 多文化"的意趣，不追求厚重的政治阴谋。
- **判据**：博得之门式的题材里看不到东方侠客——而我们要的，正是**侠客能站在骑士旁边**。
- **主角本质是穿越者**，在世界内则表现为一个**失忆的异乡佣兵**。
- **魔法常见**，不刻意血腥黑暗。
- **核心玩法是卡组构建（DBG）**，剧情先做浅，留足扩展钩子。

> 命名原则：借鉴通用的奇幻与文化概念，避免直接使用任何专有名词；原创命名优先。

## 一、世界设定

### 多文化的奇幻世界

- **类型**：奇幻。石砌城堡与护城河、骑士团与纹章、教堂钟声与彩窗；东方的城郭与江湖侠客、北地的雪原与长船、沙漠的商队与香料、圆顶的圣堂与彩绘壁龛——**诸国文化杂处，英雄传统各异**。
- **魔法**：常见的日常力量，不是稀世奇迹；法阵、符纹、附魔器物随处可见。
- **统一框架**：**先给一层能用的薄背景，后续再补**——例如"诸国并立，佣兵公会遍布各地；荒野边地散落着无人打理的古老遗迹与凶兽，冒险者应运而生"。不展开具体国别、势力与历史。

### 荒野与遗迹（副本）

- **没有双重世界**。副本就是荒野边地的一处**古代遗迹、兽巢或秘境**。
- 进入副本即离开据点、踏上远途，抵达后由入口一路深入至核心；**场景之间的路途由叙事跳跃略过**，而非逐段描绘。

## 二、角色设定

### 玩家：无名

- **本质**：穿越者——来自一个没有魔法、也没有刀剑横行的世界。
- **表象**：失忆。他醒来时想不起自己是谁、从哪来，脑海只残留着断裂的碎片。
- **核心张力**：他知道自己不属于这里，却**说不清、也不能说**。于是给自己取名「无名」。失忆既是事实，也是他唯一安全的说辞。
- **机制落实**：`世界.玩家行动审计系统` 的世界观边界**拒绝"暴露或暗示自己来自另一个世界"**——"不能说出真实身份"由审核系统在机制上兜底。
- **人设要点**：沉默，观察多于开口；面对陌生事物先看、先想，再行动；抵触被追问来历。

### NPC 同伴：坏运气

- **诨名**：坏运气。真名 **斯韦恩·哈尔弗丹**（Svein），他很少提，别人也不叫。
- **文化背景**：**北欧（北地）**。曾是北地一支佣兵战团的老兵，战团在一场远征中全军覆没，只有他活着回来——从此得名"坏运气"，圈子里少有人愿意跟他搭伙。
- **底色**：**老兵油子**，不是高尚的导师。见过太多，认了命，嘴上没一句好话，爱抱怨、爱吹嘘当年"差一点就成"的事；做事有分寸、不害人，也不会为谁把命搭进去。
- **能力**：经验老到、眼毒、判断准——本事一直都在，只是时运不济，**总在最后半步上差一口气**，半辈子没什么成就。
- **与主角**：在路边捡到失了忆的无名，收作搭子——一半是没人肯跟他，一半是顺手恻隐。给玩家入行一个先合理、后动人的理由。

> 多文化的落脚点：诸国英雄拼盘，各国都能有自己的英雄传统。坏运气选取北欧，只是一个开始。

## 三、据点（Home）

初始两个场景，均属 HOME，后续可扩展（场景系统支持任意数量）：

- **`场景.佣兵公会`**：接委托、登记名册、佣兵等候接活的地方；也是主角与坏运气初始所在。
- **`场景.酒馆`**：打探消息、歇脚、结识各色人物的地方。

---

## 四、世界导演

世界导演是**游戏全局设计师**——位于一切设定之上、代表世界本身的元层 agent。

- **层级**：他不是世界里的任何角色，**也不是神祇、命运或传说本身**；他是让这一切运转、变化的那只手。
- **职责**：感知玩家对世界造成的变化（副本归档 / 世界变化通知），据此修改游戏状态——生成新副本、编排新冲突，让世界在玩家干预下持续演化。
- **意义**：不按写死的剧本走，而是随玩家行动持续"活"起来。

## 五、卡牌 / 装备 / 消耗品映射

引擎通用概念在奇幻世界的具体化（游戏无关的机制骨架不变，只换语义）：

| 引擎概念 | 奇幻语义 | 例子 |
| --- | --- | --- |
| 卡牌（攻击/防御） | 战技 / 法术 | 基础攻击、基础防御 |
| 装备 | 武器 / 护甲 | 旧铁剑、木盾 |
| 消耗品 | 药剂 / 卷轴 | 治疗药水、爆裂卷轴 |
| 时装 | 装束 | 旧斗篷、毛皮斗篷 |
| 神器 | 圣遗物 / 古代秘宝 | 兽骨图腾 |
| 材料 | 素材 / 锻材 | 铁锭、魔素残片、兽皮绳 |

> 引擎根属性只有 hp / attack / defense / speed 四项，**没有职业系统**。因此"侠客""骑士"只能是**叙事身份**，通过 profile、战技（卡牌）、装备来体现，不能靠职业数值区分。

## 六、Demo 收敛版范围

先把新故事跑起来：

- **据点**：佣兵公会 + 酒馆（含玩家与 NPC）。
- **副本**：`副本.荒狼巢`（1 个，2 房间——兽径入口 + 狼巢深处）。
- **玩家**：无名；**NPC**：坏运气。
- **怪物**：`怪物.头狼`（野兽类，简单直接）；**神器**：`神器.兽骨图腾`（第二回合后狼群暴起，对队伍方全体强行结算一次伤害）。
- **世界导演**：游戏全局设计师。
- **世界实体**：副本生成系统、插图提示词、玩家行动审计、装备工坊、消耗品工坊、时装工坊、副本导演、世界导演、储物箱。

> 首个副本刻意做成**野兽类、不涉灵异魔法**，因为它同时承担内置测试的用途——保持简单。

## 七、未来扩展（留钩子）

- **多文化扩张**：诸国英雄拼盘逐国铺开，各国自己的英雄传统、服饰、兵器与怪物谱系。
- **统一大背景**：在薄的占位框架之上，逐步补出大陆的历史、诸国关系与共同的危机。
- **更多副本**：从荒野遗迹、兽巢，走向诸国旧都、圣堂废墟、异界秘境。
- **剧情加深**：在 DBG 核心之外，按需补充角色弧光与世界线推进。
- **主角身世**：穿越者的来处、为何记忆尽失——留作长线谜题。
