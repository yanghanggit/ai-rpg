# DBG 核心概念定义与逻辑关系总结

## 1. 独立定义

### 1.1 Modifiers（修正器 / 修改器）

- **作用域**：全局性、宏观层。
- **生命周期**：游戏对局开始前设定，贯穿整场对局直至结束。
- **性质**：改变底层游戏规则、环境参数或全局难度（如：初始生命变化、敌人全局属性倍率、特殊全局胜利条件）。
- **归属**：归属于“对局环境（Session/Run）”。

### 1.2 Affixes（词缀）

- **作用域**：局部性、个体层。
- **生命周期**：随实体（怪物或卡牌）生成而绑定，随实体消亡而消失；具有**静态永久性**（在实体存活期间持续生效，不随时间或回合自动衰减）。
- **性质**：定义实体的**固有底层行为逻辑或攻击模组**（如：攻击附带额外效果、基础属性修正、特殊被动规则）。
- **归属**：归属于“实体本身（Entity/Unit/Card）”。

### 1.3 Status Effects（状态效果 / Buff & Debuff）

- **作用域**：个体层，附着于目标单位（通常是角色或怪物）。
- **生命周期**：战斗进程中由技能、卡牌或词缀**动态触发**；具有**临时性**（受回合数限制或层数衰减机制约束）。
- **性质**：定义目标当前的**临时数值波动或异常控制状态**（如：增减攻击力、每回合损失生命、无法行动）；状态层数可叠加或驱散。
- **归属**：归属于“承受效果的目标个体（Target）”。

---

## 2. 核心逻辑关系

### 2.1 Modifiers 与 Affixes 的关系（宏观与微观）

- **层级关系**：Modifiers 是“容器层”的全局规则，Affixes 是“填充层”的个体属性。
- **干涉关系**：Modifiers 可以决定 Affixes 是否出现（如：高难度下强制怪物附带额外词缀），但 Modifiers 本身不直接等同于 Affixes。
- **区别**：Modifiers 修改“游戏怎么玩”；Affixes 定义“这个怪/卡是什么”。

### 2.2 Affixes 与 Status Effects 的关系（因与果）

- **本质区别**：Affixes 是**静态触发器**，Status Effects 是**动态标记**。
- **归属性解耦**：
  - Affixes 归属于**施加者（攻击者）**，Status Effects 归属于**承受者（目标）**。
- **独立性**：施加者死亡（Affixes 消失）不会自动清除目标身上已存在的 Status Effects；目标清除自身 Status Effects 不会影响施加者的 Affixes。

### 2.3 Affixes 触发 Status Effects 的机制（生产-消费模型）

- **逻辑链**：`Affixes（规则定义） → 满足触发条件（如普通攻击命中） → 向目标施加 Status Effects（实例化产出）`。
- **关系定性**：Affixes 是 **“生产源（Producer）”**，Status Effects 是该生产源作用于目标后产生的 **“临时产物（Product）”**。
- **耦合度**：触发机制强关联，但生命周期完全解耦且互不干扰。
