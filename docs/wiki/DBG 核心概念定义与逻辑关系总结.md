# DBG 核心概念定义与逻辑关系总结

## 1. 独立定义

### 1.1 Modifiers（修正器 / 修改器）

- **作用域**：全局性、宏观层。
- **生命周期**：游戏对局开始前设定，贯穿整场对局直至结束。
- **性质**：改变底层游戏规则、环境参数或全局难度（如：初始生命变化、敌人全局属性倍率、特殊全局胜利条件）。
- **归属**：归属于“对局环境（Session/Run）”。

### 1.2 Affixes（词缀）

- **作用域**：局部性、个体层，附着于卡牌、装备、消耗品等一次性效果载体。
- **生命周期**：随载体（`Card`/`GearItem`/`ConsumableItem`）生成而固化，仅在该载体被使用/生效的当次动作结算中套用，不产生跨回合的持续影响。
- **性质**：不含可直接量化数值的文本触发信号（如 `[穿透]:本次伤害无视目标防御`），由仲裁 LLM 在本次结算时直接解读套用。
- **归属**：归属于“载体本身（Card/GearItem/ConsumableItem）”。

---

## 2. 核心逻辑关系

### 2.1 Modifiers 与 Affixes 的关系（宏观与微观）

- **层级关系**：Modifiers 是“容器层”的全局规则，Affixes 是“填充层”的个体属性。
- **干涉关系**：Modifiers 可以决定 Affixes 是否出现（如：高难度下强制怪物附带额外词缀），但 Modifiers 本身不直接等同于 Affixes。
- **区别**：Modifiers 修改“游戏怎么玩”；Affixes 定义“这次结算多出什么效果”。
