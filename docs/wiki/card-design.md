# 卡牌设计指南（Card Design）

---

## 定位

本指南面向内容作者，回答每个字段「这样设计可以被怎样玩」：不仅说明取值含义，更说明该取值如何与手牌、其他字段联动产生策略。字段的权威语义以卡牌数据模型为准，布尔字段按「开 / 关」、数值字段按「取值区间」、词缀按「对持有者的增益 / 减益」展开，可逐步补充。

## 设计总原则

- 每个字段单一职责，玩法靠组合表达，不靠新增字段。
- 确定性字段让回合循环可运转，词缀提供语义灵活性；接受仲裁 LLM 解释带来的数值/语义偏差。
- 同一张牌的「持有」与「打出」是两个身份：设计时同时考虑它作为手牌状态与作为行动的效果。

## 身份字段

- `name`：内容身份与决策匹配键，决定 LLM 如何称呼与选择它。
- `description`：叙事锚点，只影响仲裁演出措辞，不重复数值、不改变结算。

## 数值旋钮

### cost（费用）

决定一张牌的节奏与资源取舍。

- 低费（0~1）：稳定节奏，可每回合打出——适合构筑核心、高频触发词缀。
- 高费（≥2）：爆发/终结，显著消耗能量——制造「出还是过」的取舍，应配强效果否则无人选。
- 费用只在出牌时刻收门槛，不决定能否留手。

### damage 与 hit_count（伤害与段数）

决定输出的强度与形态。

- `damage` 定单段强度，`hit_count` 定段数，多段各自独立结算。
- `damage` = 0：无直接输出，价值由 `block` 或词缀承担——纯防御或纯状态牌。
- 多段：单目标多段连击；配合 `SPREAD` 散射分配命中——在「单体爆发」与「群体扩散」间做选择。

### block（格挡）

决定持有期防御，是手牌作为「状态」的直接体现。

- 持有即生效、整回合计入有效防御——不打出也在保护持有者。
- `block` = 0：无防御贡献，是纯进攻或纯状态。
- 高 `block` 配 `retain` 或不可出，构成常驻肉盾形态。

## 布尔旋钮（开 / 关）

### playable（可出）

`playable` 决定一张牌是「选择」还是「状态」，是理解手牌双重身份的第一道门槛。

- 开（true）：常规选择，卡牌游戏的基础形态；策略由其他字段决定——`target_type` 定「打谁」，`self_target` 定「是否锁定自身」。
- 关（false）：复杂性行为的载体，不可出但仍持有，手牌意义从「可打的行动」扩展到「可持有的状态」：
  - 收益型：借其他字段转为持有期收益，如 `retain` + 回合结束词缀、`block` 常驻防御。
  - 惩罚型：不可出即代价，如减益回合结束词缀每回合末持续受损。

### exhaust（消耗）

决定一张牌是「整场一次」还是「可循环复用」。

- 开（true）：一次性兑现——适合大招、终结技、关键反转；整场只此一次，允许效果明显超模，制造「何时出手」的时机抉择。
- 关（false）：可循环——适合稳定节奏、构筑核心；效果按「可重复出现」平衡，弱效果靠频率累积价值。

### retain（保留）

决定一张牌是「当回合窗口」还是「跨回合持有」。

- 开（true）：跨回合持有——适合蓄力、等关键时机、每回合都结算的常驻效果；代价是占用下回合手牌名额，保留越多、新抽越少。
- 关（false）：当回合窗口——本回合不用即离手进弃牌堆（待洗牌回手，非永久消失），制造「现在打还是留到洗牌后」的取舍。

### ethereal（虚无）

给持有的牌加上「当回合不用即消失」的期限。

- 开（true）：限时兑现压力——适合限时强力效果、临时机会，逼玩家当回合决定用或弃。
- 关（false）：无期限——可正常流转，或配合 `retain` 长期持有。

### transferable（可传递）

把牌变成「可传递」的载体。

- 开（true）：出牌时副本进每个目标手牌，传给谁由 `target_type` 决定——传敌投递负面状态（借「非 `source` 者」反噬）、传友分发增益，方向取决于牌自身的词缀。
- 关（false）：不传递，效果只停留在本次出牌。

### self_target（锁定自身）

决定作用对象是「自身」还是「按目标类型」。

- 开（true）：锁定自身——适合自我增益、治疗、蓄力，绕过目标选择。
- 关（false）：交给 `target_type` 决定「打谁」——适合作用于他人或阵营。

## 目标类型（target_type）

决定作用范围。

- `SINGLE`：单体精确——集火、单点控制。
- `ALL`：阵营全体（目标为锚点）——群体增益、群体打击。
- `SPREAD`：阵营散射，段数随机或保底分配——不精确扩散，多段配清场。

## 词缀旋钮（持有者增益 / 减益）

词缀为自由文本，由仲裁 LLM 按触发时机解释；设计时同一时机须同时考虑对持有者的增益与减益两侧。

### on_play_affixes（即时词缀）

出牌仲裁的发起侧，出牌瞬间兑现一次。

- 增益：出牌即时获益（回血、加攻、护盾）——让「打出」本身成为收益。
- 减益：出牌代价（自伤、损失资源）——高风险高回报，用代价换超模数值。

### on_hit_affixes（受击词缀）

出牌仲裁的目标侧，被命中时触发。

- 增益：被命中反制（反伤、减伤、格挡触发）——惩罚攻击者。
- 减益：被命中承受额外（易伤、被标记、被扩散）——自身脆弱点，可借 `transferable` 转嫁给敌人。

### on_turn_end_affixes（回合结束词缀）

持有期间持续生效，每次 pass turn 结算。

- 增益：持续获益（回合末回血、回能）——常驻 buff，配 `retain` 长期持有。
- 减益：持续受损（灼烧、中毒）——负面状态，常借 `transferable` 或「非 `source` 者」转嫁给敌人。

## source（来源）

记录牌来源，供「非 `source` 者」词缀做反噬判定。

- 系统填充；设计时用「非 `source` 者」让牌在离开来源后反噬新持有者——负面状态转嫁的关键语义。

## 组合范式（逐步补充）

范式按三端化思维归类标注为「大类 / 小类」，运转端暂无对应字段、不列出。

### 攻击端

#### 前端伤害

- 一次性爆发：高 `cost` + 高 `damage` + `exhaust`。
- 代价爆发：高 `damage` + `exhaust` + 即时词缀（减益，自伤）——超模输出付自身代价。
- 集火连击：`SINGLE` + 多 `hit_count` + 高 `damage`——单体多段爆发。
- 散射清场：`SPREAD` + 多 `hit_count`——不精确扩散。
- 限时机会：`ethereal` + 高收益词缀。
- 群体打击：`ALL` + 高 `damage` + 敌阵营锚点。

#### 成长性伤害

- 持续减益传染：`transferable` + 回合结束词缀（减益）+ `retain` 传敌——敌人每回合末持续受损。

#### 铺垫性攻击支持

- 标记引爆：`transferable` + 受击词缀（减益，如标记/易伤）传敌 → 我方再用即时词缀收割。
- 传染型减益：`transferable` + 受击词缀（减益）+ `source` 反噬。
- 自我循环：`self_target` + `retain` + 即时/回合结束词缀（增益）——每回合给自己叠状态。
- 群体减益：`ALL` + 敌阵营锚点 + 即时词缀（减益，如全体易伤）。

### 防御端

#### 前端防御

- 基础防御即前端防御，无额外组合范式。

#### 成长性防御

- 防御蓄力：`block` + `retain`。
- 常驻被动：`playable` 关 + `retain` + 回合结束词缀（增益或减益）。

#### 特殊防御机制

- 反伤壁垒：`block` + 受击词缀（增益，反伤/减伤）+ `retain`——持牌高防，被打反制。
- 支援分发：`transferable` + 回合结束词缀（增益）+ 友方锚点——把增益副本发给队友。
- 群体增益：`ALL` + 己方锚点 + 即时/回合结束词缀（增益）。
