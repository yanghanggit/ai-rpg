# 神器（Artifact）

---

## 定位

神器是挂在**战斗场景实体**上的、内容作者书写的**场景级战斗修正规则**载体。它不是角色物品：不进背包、不进牌堆、不物化为卡牌；它只回答一个问题——发生在这个场景里的出牌仲裁，额外还要遵守什么。引擎对神器内容保持无感知，只在出牌仲裁时把它交给仲裁 agent 自行理解与执行。

## 构成与挂载

神器由叙事身份（名称、描述）与一组修正规则组成；规则是自然语言的指导性文本，以列表承载、为多条叠加预留空间。它经 `StageArtifactComponent` 挂在战斗场景实体的组件列表上，随副本数据序列化，在战斗房间创建时还原。规则只写世界观内可执行的指导语义，不写运行时工具或字段——内容作者不接触引擎视角。

## 仲裁时如何生效

出牌仲裁由场景实体担任仲裁 agent。结算前，仲裁任务提示词要求它先查询场景自身状态；该自检返回场上阵营与场景携带的神器。仲裁 agent 结合本次出牌上下文，自行决定如何用仲裁工具落实这些规则。因此「第 N 回合队伍方全员倒下」「怪物伤害翻倍」这类场景规则以内容数据存在，不改引擎。

## 设计意图

- 机制与内容分离：场景规则是数据，不是硬编码进仲裁系统的分支。
- 借重 LLM 的灵活性：规则由仲裁 agent 在运行时按需发现并解释，而非系统预先筛选注入，保留内容表达的空间。
- 场景级而非卡牌级：神器规则对该场景内所有出牌仲裁生效，是背景约束；卡牌词缀则属于单次出牌/受击结算。
